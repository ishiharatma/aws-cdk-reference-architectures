実施可否

✓
NEW リボン（右上）
patterns.json に既存の date フィールドがある。 ページ表示時に「今日 − 7日」と比較するだけで判定可能。追加データ不要。
✓
DRAFT リボン（左上）
patterns.json に draft: true フィールドを1行追加するだけ。 既存のカード生成ロジックをわずかに拡張する。

実装ポイント

  • カード div はすでに overflow-hidden が付いているため、リボンは追加 CSS なしで角にクリップされる
  • CSS transform: rotate(±45deg) で斜め帯を表現。position: absolute で角に固定
  • NEW 判定は Date.now() − new Date(pattern.date) ≤ 7日 をJSで計算
  • DRAFT は pattern.draft === true のフラグチェックのみ
  • リボンが重なる（NEW+DRAFT 同時）ケースもレイアウト崩れなし

変更ファイル

  • pages/index.html
    リボン用 CSS を2クラス追加（約20行）
  • pages/app.js
    createPatternCard() に NEW/DRAFT リボン HTML 生成を追加（約15行）

実装コードイメージ（抜粋）

app.js index.html (CSS) patterns.json 
// createPatternCard() 内に追加するリボン生成ロジック

const ONE_WEEK_MS = 7 * 24 * 60 * 60 * 1000;
const isNew   = (Date.now() - new Date(pattern.date).getTime()) <= ONE_WEEK_MS;
const isDraft = pattern.draft === true;

const newRibbonHTML   = isNew   ? `<div class="ribbon ribbon-new">NEW</div>`   : '';
const draftRibbonHTML = isDraft ? `<div class="ribbon ribbon-draft">DRAFT</div>` : '';

// カード HTML テンプレート内 (先頭に挿入)
return `
  <div class="pattern-card ...">
    ${newRibbonHTML}
    ${draftRibbonHTML}
    ...
  </div>
`;
